# Python for AI

Repositori ini berisi materi dan latihan untuk belajar Python sebagai bekal memahami dan mengembangkan aplikasi kecerdasan buatan (AI).

## Mulai

Pastikan Python 3 sudah terpasang, lalu clone repositori:

```bash
git clone <URL_REPOSITORI>
cd python-for-ai
```

Disarankan menggunakan virtual environment agar dependensi proyek terpisah:

```bash
python3 -m venv .venv
source .venv/bin/activate  # macOS/Linux
# Windows: .venv\Scripts\activate
```

## Menjalankan contoh

Jalankan berkas Python yang ingin dipelajari dengan perintah berikut:

```bash
python nama_file.py
```

Jika proyek menyediakan berkas notebook, instal Jupyter dan jalankan:

```bash
python -m pip install jupyter
jupyter notebook
```
